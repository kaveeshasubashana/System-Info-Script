# System Info Script 🖥️

A simple Bash script that displays system information, including:

- Hostname and Operating System
- Uptime
- CPU details
- Memory usage
- Disk usage
- Network information

---

## Prerequisites

- **VS Code** installed
- **Git Bash** or **Windows Subsystem for Linux (WSL)** for running Bash scripts on Windows
- Linux/macOS users can run it directly in the terminal

---

## How to Run in VS Code

1. **Open the project folder in VS Code**  
   - Open VS Code → File → Open Folder → select the folder containing `system_info.sh`

2. **Open the integrated terminal**  
   - open the terminal  
   - Make sure the terminal is set to **Git Bash** (or WSL if you are using it)

3. **Make the script executable** (only needed for Linux/WSL)
   ```bash
   chmod +x system_info.sh
